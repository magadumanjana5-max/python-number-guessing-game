# python-number-guessing-game

## Project Flow

1. The program chooses a random number between 1 and 100.
2. The user enters a guess.
3. The program says "Too low" or "Too high" for an incorrect guess.
4. If the input is not a whole number, the program asks for another guess without counting it as an attempt.
5. When the guess is correct, the program displays the total number of attempts and ends.

## How to Run

Make sure Python is installed, open a terminal in this project folder, and run:

```powershell
python main.py
```

On Windows, you can also use:

```powershell
py main.py
```
